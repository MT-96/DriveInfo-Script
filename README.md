# ℹ️ DriveInfo ℹ️
---------------------------------------------------------------------------------------------------------
This script prints various information about the storage devices currently connected to your Windows machine.

---------------------------------------------------------------------------------------------------------
To install:

Name a directory ***`C:\Scripts`*** and place the .ps1 file here. If using **PowerShell** you can run ***`cd C:\Scripts`*** followed by ***`./Install-DriveInfo.ps1`***. After that you'll be able to use the command **`driveinfo`** and it will print various info of connected drives.

Currently limited to what this script throws back but I will update it occasionally to make it more interesting. 😊
